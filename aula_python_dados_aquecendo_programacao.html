Aquecendo na programação com Python

Uma aula para entender os conceitos necessários para resolver as 13 atividades, sem transformar o estudo em simples cópia de respostas.

Como usar esta aula

Ordem recomendada: estude um conceito, leia o roteiro da questão, escreva sua solução e somente depois abra as dicas progressivas.

1. Entenda

Identifique quais dados entram, qual decisão precisa ser tomada e qual mensagem deve sair.

2. Planeje

Escreva o raciocínio em português ou pseudocódigo antes de programar.

3. Implemente

Converta cada passo do plano em uma instrução Python.

4. Teste

Use valores normais, valores iguais, zero, negativos e entradas com letras maiúsculas.

1. O fluxo básico de um programa

Entrada→Conversão→Processamento→Decisão→Saída

Quase todas as atividades desta lista seguem esse mesmo caminho.

# 1. Entrada
texto = input("Digite um número: ")

# 2. Conversão
numero = float(texto)

# 3. Processamento ou decisão
resultado = numero * 2

# 4. Saída
print(resultado)
Pergunta ativa: por que o valor retornado por input() precisa ser convertido antes de fazer uma conta?

2. Entrada de dados e conversão de tipos

input() sempre retorna texto. Você escolhe a conversão conforme o dado esperado.

ConversãoUsoExemplo
int()Números inteirosQuantidade de itens
float()Números com casas decimaisPreço, percentual, litros
Sem conversãoTextoTurno, combustível, letra
Atenção: valores monetários reais normalmente exigem cuidados adicionais, mas nesta introdução o curso utiliza float para praticar lógica.

3. Operadores de comparação

Uma comparação produz apenas dois resultados: True ou False.

> maior que
< menor que
>= maior ou igual
<= menor ou igual
== igual
!= diferente
idade = 18
print(idade >= 18)  # True
print(idade == 20)  # False
Erro comum: = atribui um valor; == compara dois valores.

4. Estruturas condicionais

Use condicionais quando o programa precisa escolher um caminho.

if condição_1:
    # executado quando condição_1 é verdadeira
elif condição_2:
    # executado quando condição_2 é verdadeira
else:
    # executado quando nenhuma anterior é verdadeira
Regra importante: o Python testa as condições de cima para baixo e para na primeira condição verdadeira.

Condições compostas

and

As duas condições precisam ser verdadeiras.

or

Pelo menos uma condição precisa ser verdadeira.

not

Inverte o resultado lógico.

Encadeada

Uma decisão pode ficar dentro de outra.

7. Encontrando maior e menor valor

Você pode praticar comparações manualmente ou utilizar funções nativas.

valores = [12.5, 10.0, 14.8]
maior = max(valores)
menor = min(valores)
Aprendizado: max() e min() recebem vários valores ou uma coleção e retornam o maior e o menor.

8. Ordenação

A questão 6 pede três números em ordem decrescente.

numeros = [8, 3, 12]
numeros.sort(reverse=True)
print(numeros)

sort() altera a própria lista. O argumento reverse=True inverte a ordem para decrescente.

Alternativa conceitual sem sort
Também é possível comparar e trocar posições manualmente. Essa abordagem treina condicionais, mas fica mais longa e sujeita a erros.

9. Cálculo de variação percentual

A variação mede quanto o valor novo aumentou ou diminuiu em relação ao valor anterior.

Fórmula: ((valor_novo - valor_anterior) / valor_anterior) * 100
valor_anterior = 100
valor_novo = 120
variacao = ((valor_novo - valor_anterior) / valor_anterior) * 100
Caso especial: se o valor anterior for zero, a divisão não pode ser realizada. O programa precisa tratar esse caso.

11. Validação e classificação de triângulos

andcomparaçõesigualdade

Etapa 1 — validar

a + b > c e a + c > b e b + c > a

Etapa 2 — classificar

  • Três lados iguais → equilátero.
  • Pelo menos dois lados iguais → isósceles.
  • Todos diferentes → escaleno.
Ordem recomendada das condições
Primeiro valide se existe triângulo. Só depois classifique. Na classificação, teste primeiro o caso mais específico: os três lados iguais.

13. Variação anual de vendas

variação percentualfaixasordem das condições

variacao = ((vendas_2023 - vendas_2022) / vendas_2022) * 100

Monte as faixas sem sobreposição

FaixaSugestão
Acima de 20%Bonificação
De 2% até 20%Pequena bonificação
De -10% até abaixo de 2%Planejamento de incentivos
Abaixo de -10%Corte de gastos
Interpretação adotada: o enunciado apresenta “entre 2% e -10%”. Para evitar sobreposição com a faixa anterior, trate essa região como valores de -10% até abaixo de 2%.
Dica sobre a ordem
Comece pela maior faixa e vá descendo, ou escreva limites explícitos com and. O importante é cada valor cair em apenas uma categoria.
Caso especial
Se as vendas de 2022 forem zero, não é possível dividir por esse valor. Trate essa situação antes da fórmula.

Checklist antes de considerar uma questão pronta

Entrada

Usei o tipo correto: int, float ou texto?

Condições

As faixas cobrem todos os casos sem sobreposição?

Limites

Testei igualdade, zero, negativos, empates e divisões por zero?

Saída

A mensagem informa claramente o resultado solicitado?

Testes mínimos

  • Um valor que torne a primeira condição verdadeira.
  • Um valor para cada elif.
  • Um valor que chegue ao else.
  • Valores exatamente nos limites, como 15 litros, 20%, 2% e -10%.
